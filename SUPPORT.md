# Support

English | [简体中文](SUPPORT.zh-CN.md)

Use [GitHub Discussions](https://github.com/zhangz-2018/dsh-project-orchestrator/discussions) for installation and usage questions. Use [GitHub Issues](https://github.com/zhangz-2018/dsh-project-orchestrator/issues) for reproducible defects and feature proposals.

Include the plugin, Harness, Cordis, Node.js, OS, and Git versions; the failing route or command; and redacted evidence. Do not post storage files, credentials, repository contents, or raw Transcripts publicly.

Only the compatibility matrix in `docs/compatibility.md` is supported. Best-effort community help is not an SLA.
